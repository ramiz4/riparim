# Localization

Riparim uses German (`de`, default), Albanian (`sq`) and English (`en`) through
one English physical `app/[locale]` page tree. Start with the task below;
[language boundaries](contributing-language.md) explain what must keep its original bytes.

## Add UI copy

Use typed `getMessages`/`createTranslator` from [messages.ts](../../lib/i18n/messages.ts),
or `useI18n` from [client.tsx](../../lib/i18n/client.tsx). Keep catalogs aligned;
compose rich text with React nodes, without translated HTML or a general ICU parser.
Root layout ships active common messages only. Feature `I18nMessages` providers
add needed namespaces and preserve navigation state; inactive catalogs stay out
of the browser translator bundle. Use safe [error codes](../../lib/i18n/codes.ts),
not raw provider messages. Preserve required statuses and legacy API strings;
binary downloads keep bytes/permissions and `X-Riparim-Error-Code` on localized errors.

## Add routes and navigation

[locale.ts](../../lib/i18n/locale.ts) owns route identities. German URLs are
unprefixed; SQ/EN use `/sq` and `/en`, for example `/werkstaetten`, `/sq/serviset`,
`/en/workshops`. Use `localizeHref` for public URLs and `pageIdentityPath` for
physical routes. Register shapes centrally; keep `publicAssetPaths` aligned with
`public/`. Unknown shapes return 404 before rewriting. Explicit `/de` and old
German prefixes redirect with 308, preserving safe queries.

Use [LocaleLink](../../components/locale-link.tsx) for client navigation and
`LocaleAnchor` for document navigation. Language switching preserves validated
returns/filters/hashes and drops private tokens/submission IDs. APIs, assets,
technical metadata and `/auth/bestaetigen` stay outside page localization.
[Navigation guards](../../lib/i18n/navigation-guard.tsx) confirm draft discard and
block switching during uploads/mutations/auth/deletion; pass only booleans into context.

## Display data and dates

[values.ts](../../lib/i18n/values.ts) translates labels, while requests, filters
and stored values stay canonical. Consultation language is independent of UI locale.
Workshop SQ/EN overlays must match [source hashes](../data/workshops.md#add-or-update-workshops);
never automatically translate original business, review, operator or provider text.
Editors keep approved canonical fields, revision guards and newer metadata.

Use [format.ts](../../lib/i18n/format.ts): date-only values keep their calendar day;
timestamps use `Europe/Belgrade`. Workerd lacks SQ ICU support, so shared numeric/date
formatting and [collation.ts](../../lib/i18n/collation.ts) supply equivalent output.
DE/EN use native Intl; rating/distance tie rules remain canonical.

## Preserve Auth and privacy

[Auth locale](../../lib/auth/locale.ts) allowlists callback locale; URL locale wins.
[Return validation](../../lib/auth/return-path.ts) rejects external targets and
encoded/locale-prefixed callback loops; callback/cookie paths stay `/auth/bestaetigen`.
Signup saves `preferred_locale`; only the verified own account may update it.
Switching saves with a bounded wait, then follows the URL even on failure;
`localeNotice=preference_not_saved` stays out of SEO. Native ChatGPT accounts skip
that write. Localized deletion phrases map to the existing server sentinel.

[Public metadata](../../lib/i18n/public-metadata.ts) derives canonical/reciprocal/
x-default URLs only for published profiles. Auth/private pages and private query
modes use `noindex,nofollow` without public language alternatives. Private text stays
in its document. Privacy copy retains policy meaning/date. Auth-template sources
are exact technical bytes, never translated or executed; verify adoption separately
through [Auth operations](../operations/auth-provider.md).

## Verify

Run `npm run i18n:check` and relevant [tests](testing.md). Both Worker builds include
`test:i18n-worker`; production Link tests check navigation. Browser/Worker output
must agree. Follow [customer-flow QA](customer-flow-qa.md) with isolated providers/accounts;
[historical checks](../archive/customer-flow-history.md) prove only their recorded scope.
