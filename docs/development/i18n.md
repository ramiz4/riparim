# Localization

Riparim supports `de`, `sq`, `en` through one English physical `app/[locale]`
page tree. UI copy is translated; canonical business fields, user/provider text,
storage values and compatibility URLs keep their meaning. See
[codebase language](contributing-language.md) and [QA](customer-flow-qa.md).

## Routes and links

[`locale.ts`](../../lib/i18n/locale.ts) owns page identities and public paths.
German keeps unprefixed URLs; SQ/EN use `/sq` and `/en`. Explicit `/de` and old
translated-prefix German paths redirect with 308 and retain safe query fields.
Examples: `/werkstaetten`, `/sq/serviset`, `/en/workshops`. Workshop IDs stay stable.
The proxy rewrites to shared physical identities and preserves cookies/RSC.

Use `localizeHref` for public addresses and `pageIdentityPath` for physical
identities. Add new page shapes centrally; keep `publicAssetPaths` in sync with
actual `public/` files. Unknown page shapes are rejected with 404 before rewriting.
APIs, `/auth/bestaetigen`, native auth endpoints, assets and technical metadata
remain outside page localization.

Use [`LocaleLink`](../../components/locale-link.tsx) for internal client navigation,
`LocaleAnchor` for explicit document navigation. The
[language switch](../../lib/i18n/navigation.ts) preserves profile, permitted
filters/hashes and validated login return; it drops private tokens/submission IDs.
Consultation-language filters are independent of interface locale.
Dirty/busy forms use [`useNavigationGuard`](../../lib/i18n/navigation-guard.tsx):
only booleans enter the request-local context; discard asks for confirmation,
and uploads/mutations/auth/deletion block switching until safe.

## Messages, values and formatting

[`messages.ts`](../../lib/i18n/messages.ts) provides typed `getMessages` and
`createTranslator`; [`client.tsx`](../../lib/i18n/client.tsx) provides `useI18n`.
Root layout serializes only active common messages. Feature `I18nMessages`
providers add required public/customer/management namespaces without replacing
navigation state. Inactive catalogs must not enter the browser translator bundle.
Compose rich text with React nodes; no translated HTML or general ICU parser.

[`values.ts`](../../lib/i18n/values.ts) translates display labels while request,
filter and stored values remain canonical. Keep workshop originals separate from
editorial SQ/EN overlays; their [source hashes](../data/workshops.md#sqen-display-content)
control stale-source fallbacks. Review/operator/provider content is never
automatically translated.

Use safe codes from [`codes.ts`](../../lib/i18n/codes.ts), preserving existing HTTP
statuses/legacy strings where required. Clients select local messages from codes;
raw provider errors are neither codes nor UI copy. Binary evidence downloads
retain bytes and permissions; localized errors include `X-Riparim-Error-Code`.

[`format.ts`](../../lib/i18n/format.ts) preserves date-only calendar days and uses
`Europe/Belgrade` for timestamps. Workerd lacks SQ number/date/collation ICU:
shared formatting supplies SQ separators/native rounding and equivalent numeric
dates. [`collation.ts`](../../lib/i18n/collation.ts) implements bounded SQ ordering
from [CLDR](https://github.com/unicode-org/cldr/blob/main/common/collation/sq.xml),
including Ç/Ë/digraphs; DE/EN use native Intl. Rating/distance tie rules remain
canonical. Browser and Worker output must agree.

## Auth, account and private pages

[`auth/locale.ts`](../../lib/auth/locale.ts) owns allowlisted request/callback locale
and locale-first mail callback URLs; URL locale wins over a conflicting return
prefix. [`validatedReturnPath`](../../lib/auth/return-path.ts) and server validation
reject external targets and encoded/locale-prefixed callback loops.
Callback/cookie paths stay `/auth/bestaetigen`.

Signup records `preferred_locale`. Only the verified own account may independently
PATCH `{preferredLocale}`; this preference grants no rights. Explicit switching
attempts a bounded preference save, then navigates by authoritative URL. Failure
shows `localeNotice=preference_not_saved`; exclude it from SEO URLs. Native ChatGPT
accounts skip this write. Deletion phrases are localized in
[`delete-confirmation.ts`](../../lib/i18n/delete-confirmation.ts), then mapped to
the existing server sentinel.

Editors always receive canonical approved fields and revision guards. Renames
PATCH `full_name` without replaying old metadata. Private text stays in the current
document. Auth setup displays four exact technical subject/HTML sources from
central templates; source bytes are neither translated nor executed. Provider
adoption, Go previews, readback and receipt checks follow
[auth operations](../operations/auth-provider.md).

## Metadata and verification

[`public-metadata.ts`](../../lib/i18n/public-metadata.ts) derives canonical,
reciprocal language and x-default URLs from one public identity. Only published
profiles qualify. Auth/account/business/admin and private query modes have
`noindex,nofollow` without public language alternatives. Privacy content retains
its original policy meaning/date in its own typed catalog.

```sh
npm run i18n:check
npm test
```

Checks cover parity/nonempty/placeholders, typed caller contracts, localized paths,
safe returns, controls, values/Intl, metadata and private boundaries. Both actual
Worker builds run `test:i18n-worker`; production Link tests cover navigation.
Use isolated providers/accounts and perform the [browser matrix](customer-flow-qa.md).
Past acceptance scope and provider limitations are in
[customer-flow history](../archive/customer-flow-history.md).
